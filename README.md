# qemu-anchor-plugin

TCG-плагин для QEMU (x86/x86_64), который ловит момент, когда гостевая программа
доходит до нужного кода, и снимает в этот момент регистры и кусок памяти.
Делал под Windows-гостей: умеет ходить по PEB и понимать, в каком модуле сработало,
и дампить PE-образ целиком.

Момент («якорь») задается сигнатурой байтов (`sig=`, `??` как маска) или адресом
(`va=`). Якорей можно несколько, каждый начинается с `anchor=new`.

## Сборка

Нужны заголовки QEMU (`qemu-plugin.h`) и glib. Проверял на QEMU 11.1.

```bash
gcc -O2 -shared -fPIC $(pkg-config --cflags glib-2.0) anchor.c -o libanchor.so \
    $(pkg-config --libs glib-2.0) -lm
```

## Пример

```bash
qemu-system-x86_64 ... -plugin ./libanchor.so,out=hits.jsonl,dumpdir=dumps,\
sig=4883EC28??8B05,user_only=1,regs=1,dumpva=rcx,dumplen=0x100,once=1
```

Каждое срабатывание пишется строкой JSON в `out`: rip, модуль и rva, регистры,
куда лег дамп, энтропия и sha256 дампа, если включены.

## Параметры

Общие:

| параметр | что делает |
|---|---|
| `out` | файл для JSONL, без него в лог QEMU |
| `dumpdir` | куда класть дампы |
| `sock` | unix-сокет, туда же уходят события (для внешнего скрипта) |
| `dedup`, `entropy`, `sha256` | одинаковые дампы не писать повторно, считать энтропию и хеш |
| `async_write`, `fsync_every` | запись дампов в отдельном потоке, fsync |
| `peb_walk`, `peb_ttl` | искать модуль через PEB и сколько держать кеш |
| `guest_bits` | 32 или 64 |
| `teb_peb_off`, `peb_ldr_off`, `ldr_*_off` | смещения структур, если у гостя они другие |

На каждый якорь:

| параметр | что делает |
|---|---|
| `sig` / `va` | по байтам или по адресу |
| `user_only` | только user mode |
| `cond` | условие, например `rcx==0x10 && u32(rsp+8)!=0` |
| `regs` | писать регистры |
| `dumpva`, `dumplen` | что дампить, выражения как в `cond` |
| `mode` | `raw` или `pe` (дамп образа по заголовкам) |
| `once`, `count`, `every`, `every_per_vcpu` | сколько раз и на каком по счету срабатывать |
| `after` | не срабатывать первые N секунд |
| `pause` | пометить событие `pause_requested`, чтобы скрипт по сокету остановил ВМ |
| `exit` | выйти из QEMU после срабатывания |

В выражениях есть регистры (`rax`, `eax`, `al`, ...), числа, `+ - & | ^ ~`
и чтение памяти `u8()`, `u16()`, `u32()`, `u64()`. В `cond` еще сравнения
`== != < > <= >=`, `&&`, `||` и `!`.

## Ограничения

- сигнатура длиннее 15 байт ищется только внутри одного TB, плагин об этом предупредит
- `exit=1` обрывает вывод других плагинов (drcov и т.п.), лучше `pause=1`
